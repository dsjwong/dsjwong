### Selected work

**[Crop Pest Detection Benchmark](https://github.com/dsjwong/cv-crop-pest-object-detection-benchmarking)**
Six architectures — three detectors, three classifiers — trained head-to-head on a
twelve-class pest dataset. ViT reached 93.4% accuracy, YOLOv11 reached 0.825 mAP@0.5.
End-to-end pipeline with YOLO-to-COCO conversion, early stopping and XAI visualisations.
Completed on exchange at UNSW Sydney.

**[Library Management System](https://github.com/dsjwong/library-management-system)**
Spring Boot and React, with 169 tests — 98 unit and 71 integration, the integration suite
running against a real PostgreSQL container rather than an in-memory stand-in. Flyway
migrations, JWT authentication, role-based access across three user types.

**[Safe Reinforcement Learning with Runtime Shielding](https://github.com/dsjwong/ai-safe-reinforcement-learning-shield)**
A Q-learning agent wrapped in a learned safety shield that vets each action before it
reaches the environment, so unsafe moves are filtered at runtime rather than penalised
afterwards.

**[C++ Fundamentals](https://github.com/dsjwong/cpp-fundamentals)**
Twelve C++ projects collected into one repository — OOP, templates, data structures,
recursion. Every one compiles cleanly with `g++ -std=c++17`.
